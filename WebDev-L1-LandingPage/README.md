## 📌 Project Overview
ApexFlow is a responsive, modern static landing page designed for a team workspace and collaboration platform. The layout features a dark theme, gradient typography, sticky navigation, interactive preview dashboard, feature cards, social proof testimonials, and a clear call-to-action (CTA).

---

## ✨ Features Checklist
- [x] **Sticky Navigation Bar:** Frosted glassmorphism header with logo, navigation links, and CTA buttons.
- [x] **Hero Section:** Engaging headline with gradient text, subtitle, action buttons, and mock dashboard metrics card.
- [x] **Features Section (CSS Grid):** 4 feature cards highlighting real-time sync, security, analytics, and AI automation.
- [x] **About & Statistics Section:** Brand story with key metric callouts.
- [x] **Social Proof / Testimonials:** Responsive customer review cards with star ratings.
- [x] **Call-To-Action (CTA):** Email input subscription with responsive button.
- [x] **Footer:** Multi-column layout with quick links, social media buttons, and copyright.
- [x] **Fully Responsive:** Mobile, tablet, and desktop friendly.
- [x] **Pure CSS & Semantic HTML5:** Clean code without external JS dependencies.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic markup structure
- **CSS3:** Flexbox, CSS Grid, Custom Properties, Media Queries
- **Typography:** Google Fonts (Plus Jakarta Sans)
