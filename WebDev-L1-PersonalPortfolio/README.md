- [x] **Profile / Hero Section:** Name, role title, avatar, short bio, and CTA buttons.
- [x] **About Me Section:** Background summary, education, and current role.
- [x] **Skills Section (CSS Grid):** Visual cards highlighting HTML5, CSS3, JavaScript, Git & GitHub, and responsive design.

- [x] **Smooth Scrolling:** Effortless navigation between all sections.
- [x] **Responsive Design:** Looks great on mobile devices, tablets, and desktop computers.
